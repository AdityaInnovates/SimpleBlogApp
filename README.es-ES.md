

# Proyecto Colaborativo de Blog de DSA 
Dale estrella al repositorio ⭐️

¡Bienvenidos al **Proyecto Colaborativo de Blog de DSA**! Este repositorio invita a colaboradores de todos los niveles a compartir sus conocimientos sobre Estructuras de Datos y Algoritmos (DSA) utilizando Python. Ya seas un principiante o un programador experimentado, tus contribuciones pueden ayudar a los estudiantes a comprender mejor los conceptos de DSA.
 
## 📁 Estructura del Proyecto
 
- **blogslist.json**: Un archivo JSON ubicado en el directorio raíz donde los colaboradores agregan los detalles de su blog.
- **blogs/**: Una carpeta que contiene archivos markdown (`.md`) con el contenido principal de cada blog. 

## 📝 Pautas de Contribución
 
### 1. Agregar una nueva publicación de blog

1. **Crear un ID único para el blog**([Generador de ID aleatorio](https://www.uuidgenerator.net/)): 
   - Genera un ID único y aleatorio para tu publicación.
   
2. **Actualizar `blogslist.json`**:
   - Abre `blogslist.json` en el directorio raíz. 
   - Agrega una nueva entrada con el siguiente formato:
     ```json
     { 
       "id": "unique_blog_id",    // Unique ID for the blog
       "image": "path/to/image",  // Link to the image (if any)
       "title": "Blog Title",     // Title of the blog
       "description": "Short Description"  // Brief summary
     }
     ```

3. **Crear el contenido del blog**([Editor de Markdown](https://pandao.github.io/editor.md/en.html "Editor de Markdown")):
   - En la carpeta `blogs`, crea un nuevo archivo markdown con el nombre de tu ID de blog (por ejemplo, `unique_blog_id.md`).
   - Agrega el contenido principal de tu publicación en el archivo markdown.

### 2. Contribuciones al Frontend

Si tienes experiencia en programación, te invitamos a mejorar el proyecto:
- Actualizando los archivos **HTML** y **CSS**.
- Añadiendo interactividad con **JavaScript**.
- Asegurando que el sitio web sea responsivo y visualmente atractivo.

### 3. Solicitudes de Funcionalidades y Problemas (Issues)

Si deseas sugerir una nueva funcionalidad:
1. **Crear un Issue**: Describe brevemente la funcionalidad o el problema y asígnale la etiqueta correspondiente.
2. **Esperar la aprobación**: Espera a que los mantenedores del proyecto lo revisen y aprueben antes de proceder.
